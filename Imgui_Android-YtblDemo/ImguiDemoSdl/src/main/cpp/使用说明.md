# Ytbl 液态玻璃 · 使用说明(快速接入)

液态玻璃 UI 库(ImGui + OpenGL ES 3 渲染)。

## 一、目录结构

| 文件 | 说明 |
|---|---|
| **ytbl_api.h** | **唯一需要包含的外部接口**。所有尺寸/颜色/效果参数都在这个文件里改;文件内不含任何注释,所有说明见本文件 |
| ytbl.h / ytbl.cpp | 库本体(液态玻璃组件 + AGSL→GLSL 折射着色器) |
| ytbl_shaders.h / ytbl_backdrop.h / ytbl_config.h / ytbl_spring.h | 库内部文件,不需要改 |
| README.md | 库的完整教程(深入定制 GlassParams / 绘制回调槽时再看) |

## 二、依赖

- Dear ImGui(imgui.h、imgui_internal.h 在头文件搜索路径)
- OpenGL ES 3(GLES3/gl3.h)
- C++17(外部接口使用了 inline 变量)

## 三、三步接入

**1. 把整个 `ytbl` 文件夹放进工程**,头文件搜索路径加上它的父目录。

**2. 源文件只需要编译 `ytbl.cpp` 一个**,其余全是头文件。Android.mk 示例:

```make
LOCAL_C_INCLUDES += $(LOCAL_PATH)            # 保证能 #include "ytbl/ytbl_api.h"
LOCAL_SRC_FILES  += ytbl/ytbl.cpp
LOCAL_CPPFLAGS   += -std=c++17
LOCAL_LDLIBS     += -lGLESv3 -lEGL -llog
```

**3. 宿主代码只需要 3 行:**

```cpp
#include "ytbl/ytbl_api.h"        // 唯一需要包含的头

ytbl_api::Init();                 // 1 启动时调用一次(GL + ImGui 就绪后)
ytbl_api::Tick();                 // 2 每帧调用一次(ImGui::NewFrame() 之前)
ytbl_api::DrawAll();              // 3 每帧调用一次(ImGui::Begin/End 内部)
```

## 四、最小完整示例

```cpp
#include "imgui.h"
#include "ytbl/ytbl_api.h"

static bool g_Inited = false;

void Frame() {                            // 你的渲染循环, 每帧调用
    if (!g_Inited) {                      // 首帧初始化一次
        ytbl_api::Init();
        g_Inited = true;
    }

    ytbl_api::Tick();                     // 1 清空上一帧玻璃任务

    ImGui::NewFrame();
    ImGui::Begin("Demo", nullptr, ImGuiWindowFlags_AlwaysAutoResize);
    ytbl_api::DrawAll();                  // 2 一行画出全部组件
    ImGui::End();
    ImGui::Render();

    // ... 你原有的 glClearColor / glClear /
    //     ImGui_ImplOpenGL3_RenderDrawData(ImGui::GetDrawData()) / SwapBuffers ...
}
```

## 五、接口一览与单独调用

```cpp
bool clicked = ytbl_api::DrawButton();  // 按钮: true = 本帧被点击
bool flipped = ytbl_api::DrawToggle();  // 开关: true = 状态翻转(状态已回写 toggleOn)
bool changed = ytbl_api::DrawSlider();  // 滑块: true = 值变化(值已回写 sliderValue)
int  index   = ytbl_api::DrawTabs();    // 标签栏: 返回选中下标(已回写 tabIndex)

// 在任意位置(屏幕像素坐标)画一块自定义玻璃, 折射"身后已绘制的内容":
ytbl_api::DrawPanel(ImVec2(40, 40), ImVec2(360, 160));

// 模态弹窗(遮罩 + 玻璃卡片 + 缩放弹簧入场/退场):
ytbl_api::OpenDialog();   // 打开(任意 ImGui::Begin/End 内调用)
ytbl_api::DrawDialog();   // 每帧调用一次; 必须在窗口内容画完之后(遮罩盖住内容)
                          // 结果自动回写 dialogResult: 1=点遮罩/取消 2=确定
ytbl_api::CloseDialog(2); // 主动关闭(带退场弹簧), 结果可自定义
int r = ytbl_api::GetDialogResult(); // 最近一次结果(0=无 1=取消 2=确定)
```

## 六、调参数(全部在 ytbl_api.h 的参数区)

| 参数 | 含义 |
|---|---|
| `density` / `lightTheme` | dp→px 倍率 / 白色主题开关 |
| `buttonWidthDp` `buttonHeightDp` `buttonText` `buttonTextSp` `buttonTextColor` | 按钮尺寸与文字 |
| `buttonTintOn` `buttonTint` `buttonSurfaceOn` `buttonSurface` | 按钮着色层 / 表面层 |
| `toggleOn` `toggleAccent` `toggleTrack` | 开关状态 / 强调色 / 轨道色 |
| `sliderMin` `sliderMax` `sliderValue` `sliderAccent` | 滑块范围 / 当前值 / 强调色 |
| `tabCount` `tabIndex` `tabLabel0~7` `tabsAccent` `tabsContainer` | 标签栏内容与颜色 |
| `panelCornerDp` `panelHeightDp` | 玻璃面板圆角 / 高度 |
| `panelBlurDp` | 背景模糊半径 |
| `panelRefractionHeightDp` `panelRefractionAmountDp` `panelDepthEffect` | 折射高度 / 强度 / 景深 |
| `panelChromatic` `panelDispersion` | 色散开关 / 强度 |
| `panelVibrancy` `panelSurface` `panelShadowAlpha` | 鲜艳度 / 表面着色 / 外阴影 |
| `dialogTitle` `dialogMessage` `dialogResult` | 弹窗标题 / 正文 / 最近结果(1=点遮罩或取消, 2=确定, 0=无) |

- 颜色一律 ARGB 格式 `0xAARRGGBB`(例如 `0xFF0091FF` = 不透明蓝色)。
- 状态类参数(`toggleOn` / `sliderValue` / `tabIndex`)在组件里操作后会**自动回写**;
  反过来在参数区改了它们, 下一帧立即生效。

## 七、注意事项

1. `Tick()` 必须每帧调用:内部会清空玻璃任务池(容量 64/帧),不清空会累积直到耗尽任务池。
2. 玻璃折射的是**同一帧里画在它身后的内容**:先画背景/文字/图片,再画玻璃。
3. 所有调用必须在渲染线程、GL 上下文 current、ImGui 上下文已创建时进行;组件不是线程安全的。
4. 退出前在 GL 上下文仍然 current 时调用 `ytbl::Shutdown()` 释放 GL 资源。
5. 更深入的定制(5 个绘制回调槽、GlassParams 全部参数、
   InteractiveHighlight 交互高光、动态增删标签)见同目录 README.md。
6. `Init()` 可安全重复调用;返回 `false` = 着色器编译失败(查看驱动日志)。
7. `DrawDialog()` 内部自动推进弹簧(不要再手动 `Step()`);弹窗未打开时是空操作。
